# build/
# This directory is populated by `npm run build` (Style Dictionary).
# It is intentionally kept in source control so that consumers can reference
# the latest compiled tokens without running the build themselves.
#
# Generated sub-directories:
#   build/css/variables.css   – CSS custom properties
#   build/js/tokens.js        – ES module export
#   build/js/tokens.d.ts      – TypeScript declarations
#   build/json/tokens.json    – Nested JSON
